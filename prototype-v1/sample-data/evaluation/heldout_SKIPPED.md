# Deliberately excluded from the held-out set

These documents were available but are **not** labelled, because their domain
is genuinely arguable and inventing a gold label would make the evaluation
measure my opinion rather than the model.

| File | Why skipped |
|---|---|
| `Information Technology Act 2000` | Spans cybercrime (Criminal), data protection, and e-contracts. No single correct answer |
| `SpecificReliefAct(eng)` | Remedies statute — sits between Contract and Civil Procedure |
| `Arbitration and Conciliation Act 1996` | Arbitration is dispute resolution; Contract or Civil Procedure are both arguable |
| `arbitration clause`, `arbitration clause 2` | Same ambiguity as above |
| `non compete clause`, `non compete clause 2` | Restrictive covenants are both Contract and Labour |
| `Niranjan Shankar Golikari case` | The leading case on negative covenants in employment — Contract and Labour both defensible |
| `Clause Type`, `Risky Patterns clause` | Clause taxonomies spanning every contract type |
| `IndianContractActPart7...Indemnity` | Duplicate of the s.124 material already included |
| All Hindi editions | The model is English-only; scoring them measures nothing about accuracy |

Excluding these costs coverage and is the right trade: a test set is only
worth what its labels are worth.
